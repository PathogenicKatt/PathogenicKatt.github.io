# API & API Keys

This is a short intro for the API-focused notes I’ll be covering under the notes section of the site.

APIs are one of the most important parts of modern systems. They allow applications to communicate with each other, exchange data, and expose functionality to users and other services. But because they sit in front of real data and real logic, they are also a common target in application security research.

In the coming notes, I’ll be looking at the basics of APIs, how they work, and how API keys are used in authentication and authorization. I want to cover the differences between simple API keys, bearer tokens, and more advanced identity flows, as well as the mistakes that can make them insecure.

The goal is not just to read about APIs in theory, but to understand how they can be abused, misconfigured, or poorly implemented in real systems.

This will include topics such as:
- API structure and endpoints
- API key handling
- authentication vs authorization
- weak or exposed secrets
- rate limiting and abuse prevention
- common API vulnerabilities
- practical testing ideas for API security

These notes are meant to be a foundation for deeper API hacking content later on, and they’ll be expanded in the notes section as I continue learning.
