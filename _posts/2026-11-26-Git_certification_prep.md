# Git: Building a Foundation

I've started working through Microsoft Learn's **GitHub Foundations** course, with the goal of sitting the certification exam. I know how to use Git, I've been using it for my projects, and my website but i am not an expert and i want to be one for git.

This post is the first in a series of study notes. I'm writing them for myself, but also for anyone else working toward the same certification, or anyone who wants to understand Git at a deeper level than the usual cheat sheet.

## What is version control?

Version control is a system that records changes to files over time, so you can recall specific versions later.

The course uses an aviation example: imagine you're a developer writing software for commercial airliners. Quality control is critical. One unreviewed change in the wrong place could have catastrophic consequences, people could die. Version control lets you see every change, who made it, and why, and the cool part is that it lets you roll back if something goes wrong.

Git is a **distributed** version control system. Every clone contains the complete history of the project, so you can work offline, and there's no single point of failure. That's the difference between Git and older centralised systems like Subversion.

## Learning objectives
